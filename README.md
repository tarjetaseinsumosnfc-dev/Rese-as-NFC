# Reseñas NFC Nicaragua 🇳🇮

Aplicación interactiva de reseñas NFC para negocios locales en Nicaragua. Permite a los clientes dejar reseñas de 5 estrellas en Google Maps tocando una tarjeta NFC.

## 🎯 Características

- **Tecnología NFC**: Integración con tarjetas NFC para facilitar reseñas
- **Google Maps**: Sincronización con Google Maps
- **Planes flexibles**: Múltiples combos según el tipo de negocio
- **Demo en vivo**: Prueba la funcionalidad antes de suscribirse
- **Interfaz moderna**: Diseño responsivo y atractivo

## 🚀 Tecnologías

- **Next.js 16.3.0** - Framework de React
- **React 19** - Librería UI
- **TypeScript** - Tipado estático
- **Tailwind CSS 3.3.1** - Estilos
- **Lucide React 1.16.0** - Iconos

## 📦 Instalación

```bash
# Clonar el repositorio
git clone https://github.com/tarjetaseinsumosnfc-dev/Rese-as-NFC.git

# Entrar al directorio
cd Rese-as-NFC

# Instalar dependencias
npm install

# Ejecutar en desarrollo
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

1. **Combo Starter** - Ideal para negocios individuales
2. **Combo Restaurante & Gastrobar** - Para establecimientos de comida
3. **Combo Movilidad** - Para servicios de transporte
4. **Planes personalizados** - Consulta para soluciones custom
